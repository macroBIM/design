주장

PF(potential field)를 통해, 입력이 번거로운 다음 항목을 자동 배치할 수 있다.
1

간섭 회피 배치

덕트·매입물 자리가 단면마다 다르고, 간섭을 피한 자리를 사람이 하나씩 잡아야 한다

3

지지 종방향 배치

갈고리 철근이 지지하는 종방향 철근을 배치

종방향 자리가 갈고리에, 갈고리 치수가 종방향에 달림 (서로가 서로의 입력)

03방법 — 장(PF)과 J 최소화
철근의 자리는 사람이 적지 않는다 — 자리·길이·코너는 J 의 최소점에서 나온다. 입력은 「어떤 형상을, 대략 어디에, 몇 개, 얼마 간격으로」.
장만드는 것철근에 하는 일
끌어당기는 장콘크리트 피복면 (외곽·개구부 면)가장 가까운 피복선에 앉힌다
미는 장덕트·매입물·이미 놓인 철근겹치면 옆으로 밀어낸다 (이웃끼리 평형까지)
간격 장설계자 입력 ctc·ctcmin·ctcmax·rangectc 자리로 되돌리고, 한계를 벗어나는 순간 힘이 켜진다
자르는 장격벽 개구부밀린 자리에서 토막낸다 (미는 것이 먼저)
정착장종방향 철근갈고리 다리·몸통이 그 철근을 물거나 받친다

03방법 — 장(PF)과 J 최소화

한 J 안에서 끌림·밀림·간격이 동시에 겨룬다

끌림

가까운 면이 저절로 이긴다. min 은 규칙이 아니라 거리의 정의

밀림 · 간격

한계를 넘는 순간(g<0)에만 힘이 생긴다. ctcmin·range 는 딱딱하게, ctcmax 는 되내려가게. B 는 한쪽 배리어

배치한계 · 복귀

ctc 자리로 복귀. range 는 배치한계

사전식 (lexicographic)

위반 없는 자리 중 J 최소, 없으면 가장 얕게 무는 자리

04프로그램 구성 — J 를 세우는 곳
끌림과 밀림이 한 함수 안에서 더해진다. 밀림 항은 겹칠 때(g<0)만 켜진다. jfield.js · energy (줄임)
JS · jfield.js · UTF-8 
energy: function (pose, seg, cons, ducts, placed, lpts, assign) {
  let J = 0;
  // ① 끌림 — 배정된 피복면까지의 거리² (침범 쪽은 K_COV 배)
  pts.forEach((p, i) => { const g = this.slack(p.x, p.y, c);
    J += g * g * (g < 0 ? K.K_COV : 1); });
  // ② 덕트 — 순간격을 못 지키면 벌점
  (ducts||[]).forEach(d => { const g = this.segToPoint(pts, d) - need;
    if (g < 0) { const e = this.clrRes(g); J += e.r * e.r; } });
  // ③ 앞서 놓인 횡방향 철근 (같은 z) — 선분끼리
  (placed||[]).forEach(q => { if (!this.sameZ(q, seg)) return;
    this.clearPairs(pts, q.p1, q.p2).forEach(n => {
      const g = n.d - (q.dia + seg.dia)/2;
      if (g < 0) { const e = this.clrRes(g, K.K_TRE); J += e.r*e.r; } }); });
  // ④ 앞서 놓인 종방향 철근 (단면에서 점)
  (lpts||[]).forEach(q => { const g = this.segToPoint(pts, q) - this.lreNeed(q, seg.dia);
    if (g < 0) { const e = this.clrRes(g, K.K_BAR); J += e.r*e.r; } });
  // ⑤⑥ 갈고리 — 종방향에 걸림 · 면과 평행
  if (seg.hook && seg.hookQ) J += this.hookEnergy(pose, seg);
  if (seg.hook && seg.parW)  J += this.parEnergy(pose, seg);
  // ⓪ 제자리 항 — 입력 자세(init)에서 벗어난 만큼
  J += K.K_AXIAL*ax*ax + K.K_ANCHOR*(pp*pp + at*at);
  return J;
}

// settle — 조각 하나를 두 단계로
const r1 = this.alternate(pose0, seg, cons, [], [], []);   // 1단계: 끌림만
const start = { cx: r1.pose.cx + nx/nl*nud,                // 안쪽으로 1 mm

const r2 = this.alternate(start, seg, cons, ducts, placed, lpts); // 2단계: 한 J

// descend — 자세 (cx, cy, θ) 세 자유도의 LM 하강
let last = this.energy(pose, seg, cons, ducts, placed, lpts, assign);
for (; i < K.ITER; i++) {
  const rows = this.residuals(pose, seg, cons, ducts, placed, lpts, assign);
  // H = AᵀA , g = Aᵀr (가우스-뉴턴) · 대각에 λ (Marquardt)
  const d  = this.solve3(A, [-g[0], -g[1], -g[2]]);
  const nx = { cx: pose.cx+d[0], cy: pose.cy+d[1], th: /* init ± THMAX */ };
  const Jn = this.energy(nx, seg, cons, ducts, placed, lpts, assign);
  if (Jn <= last && !bad) {           // J 가 내려가면 받는다
    pose = nx; last = Jn; lam = Math.max(lam*0.3, 1e-12);
    if (move < K.TOL) break;          // 걸음 < 1e-4 mm → 평형
  } else { lam *= 8; if (lam > 1e12) break; }  // 안 내려가면 잔걸음
}
